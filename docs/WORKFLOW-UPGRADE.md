# تحسين رحلة العمل والجاهزية — 1 نوفمبر 2026

تم تنفيذ المرحلة المقترحة ذات الأولوية داخل تطبيق React الحالي، مع الحفاظ على نظام التصميم والبيانات الأصلية والحسابات والصلاحيات.

## التغييرات

- الرئيسية التشغيلية تعرض المصدر النشط، الإصدار، تاريخ اللقطة أو آخر تغيير للمصدر، وحالة الفترة.
- رحلة من خمس خطوات: إدخال البيانات، الجودة، التصنيف، إعداد المخرجات، والمراجعة. كل خطوة تفتح شاشة العمل ذات الصلة.
- مركز جاهزية مشتق من البيانات، مع تصفية الموانع ومهام المراجعة والمتابعة، وتوجيه إلى الخطوة التالية. الرصيد المتوازن لا يعرض اعتمادًا تلقائيًا، ولا تتحول البيانات المفقودة إلى نتيجة مكتملة.
- مهام التسوية توضح الفرق الفعلي، حالات الالتباس، والبنود الزمنية. قيمة الحركات الملتبسة تشمل سجلات الطرفين وتوسم بأنها ليست فرق تسوية أو دقة مطابقة.
- دليل الأقسام الثلاثة أصبح قابلًا للإظهار عند الطلب. الرسم التاريخي متاح في صفحة التحليل بدل تكراره على الرئيسية.
- لوحة تفاصيل رقم مشتركة بين مؤشرات الرئيسية والتحليل وبنود القوائم. تعرض القيمة والمعادلة والإصدار والحسابات ذات الصلة فقط، مع الملف والورقة والصف. إجمالي حقوق الملكية يشمل نتيجة الفترة مرة واحدة.
- بيانات سبتمبر لا تستخدم حسابات أكتوبر أو تسويته كدليل بديل. عند غياب تفاصيل المقارنة تظهر الإجماليات مع سبب غياب صفوف المصدر.
- لوحة التفاصيل غير حوارية على سطح المكتب، مع إزاحة المحتوى لحماية إمكانية استخدام الصفحة. على الهاتف تستخدم حوارًا أصليًا مع إغلاق Escape وعودة التركيز للزر السابق.
- أدوات العرض التجريبي انتقلت من زر عائم إلى قائمة في شريط الأدوات، مع إبقاء تبديل الأدوار والسيناريوهات متاحًا.

## التحقق الفعلي

- `npm run build` نجح بعد التعديلات النهائية.
- 47 اختبار وحدة في 7 ملفات؛ منها 8 اختبارات جديدة لقواعد الجاهزية والأدلة المصدرية.
- `verification/workflow-upgrade.cjs`: نجحت 8 مجموعات تحقق للواجهة، وفحص 5 عروض شاشة: 320 و375 و768 و1024 و1440، دون تجاوز أفقي أو أخطاء JavaScript.
- إعادة فحص تدفقات الاستيراد والاعتماد: 6 حالات ناجحة. إعادة فحص حالات المطابقة والقيود والتركيز: 5 حالات ناجحة.
- صور العربية والهاتف ولوحة التفاصيل والإنجليزية الداكنة محفوظة في `verification/workflow-*.png`، والنتائج في `verification/workflow-upgrade.json`.

هذه متابعة جاهزية محلية، وليست إجراء إقفال خادمي. تبقى القوائم مسودات حتى يتوفر مسار اعتمادها؛ اعتماد التسوية لا يعتمدها. لم تُضف موازنة مختلقة أو حفظًا دائمًا أو معالجة Excel أو Backend أو رفعًا إلى GitHub ضمن هذه المرحلة.
